# 内村星弥の左脳

内村星弥の仕事・実績・制作物を紹介するポートフォリオです。
HTML、CSS、JavaScriptで構成した静的サイトで、ビルドやパッケージのインストールは不要です。

## ローカルで表示する

このディレクトリで次のコマンドを実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザでローカルサーバーの8000番ポートを開きます。GitHub Pagesなどの静的ホスティングでも、ファイルをそのまま配信できます。

## 更新する場所

- `index.html`：プロフィール、実績、経歴、制作物、メールアドレス
- `assets/style.css`：配色、文字、レイアウト、スマートフォン対応
- `assets/site.js`：モバイルメニュー、制作物の絞り込み、画像拡大
- `assets/favicon.svg`：サイトのアイコン
- `img/`：既存の制作物とプロフィール画像

制作物を追加するときは、ギャラリーの `data-category`（`banner` または `ai`）、`data-full`、`data-title` と画像の代替テキストも設定します。「すべて」の件数表示も更新してください。

実績と経歴は2026年11月3日付の職務経歴書・履歴書をもとに更新しています。現職の入社年月は本人確認済みの2025年8月です。売上は担当事業・顧客の実績と本人の担当範囲を分けて記載しています。公開用に確認済みのメールアドレスのみ掲載し、履歴書PDF自体はサイトに含めていません。

## 更新後に確認すること

PCとスマートフォンの両方で、文字や画像のはみ出し、メニューの移動、実績詳細の開閉、制作物の絞り込みと画像拡大を確認します。画像は拡大後に左右キーで切り替え、Escapeキーで閉じられます。連絡先はメールアプリを開くリンクです。

```sh
node --check assets/site.js
```

サイト内で読み込む画像、スタイル、スクリプトはすべて同じサイト内に置いています。
